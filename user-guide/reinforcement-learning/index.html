    Institutional Reinforcement Learning (pyalloq[rl])¶

    pyalloq[rl] provides an institutional Reinforcement Learning ecosystem that strictly decouples your feature engineering pipeline (pyalloq-features) from continuous-control environments (POMDPPortfolioEnv, MetaPortfolioEnv), non-linear market impact models (AlmgrenChrissCostModel), online risk-adjusted rewards, and policy training (SB3PortfolioAgent, DeepHedgingTrajectoryTrainer, HierarchicalMetaRLAllocator).

    1. Evolvable State Spaces (spaces.Dict & DictFlattenWrapper)¶

    To allow your RL agent to ingest technical indicators today and MiniRocket or TimesFM embeddings tomorrow without rewriting the environment, POMDPPortfolioEnv emits a 3-key gymnasium.spaces.Dict observation:

    Dictionary Key Shape Description
    "market_state" (lookback_window, n_assets, n_features) Dynamically sized 3D feature tensor (channel 0 is simple returns; channels 1..F-1 are FeaturePipeline outputs).
    "current_weights" (n_assets,) Previous step's drifted risky portfolio weights \(w_{t-1}\).
    "portfolio_meta" (3,) Internal friction & regime meta-state: [unrealized_drawdown, cash_reserve, w2_distance].

    When connecting to standard Multi-Layer Perceptron (MLP) policies in stable-baselines3, DictFlattenWrapper automatically flattens this spaces.Dict into a single 1D spaces.Box vector and provides .unflatten(flat_obs) to reconstruct the 3D tensor structure for custom Spatio-Temporal Attention extractors.

    from pyalloq_features.core.pipeline import FeaturePipeline
from pyalloq_features.transformers.technical import TechnicalIndicator
from pyalloq.rl import POMDPPortfolioEnv, DictFlattenWrapper, FeatureNormalizationWrapper

feature_pipeline = FeaturePipeline().add(
    TechnicalIndicator("RSI", timeperiod=14)
)

env = POMDPPortfolioEnv(
    scenario_data=scenario_data,       # 3D (M, T, N) ScenarioMarketData
    feature_pipeline=feature_pipeline, # Lazily evaluated & cached per sampled path
    lookback_window=20,
    include_cash=True,
    projection_mode="softmax",         # "softmax", "dirichlet", or "relu_l1"
)

# Normalize rolling features and flatten for MLP policies
wrapped_env = DictFlattenWrapper(FeatureNormalizationWrapper(env))

    2. The Multiverse POMDP Environment (POMDPPortfolioEnv)¶

    Historical financial series only provide a single realization of the past. POMDPPortfolioEnv ingests a 3D ScenarioMarketData cube \((M, T, N)\) generated by pyalloq-simulation (such as GMMRegimeGenerator or GARCHEVTCopulaGenerator):

    • Synthetic Path Spawning: On every reset(), the agent is spawned into a randomly sampled trajectory \(m \in \{0, \dots, M-1\}\), preventing overfitting to a single historical timeline.
    • Lazy Feature Caching: If a FeaturePipeline is attached, scenario_data.get_path(m, feature_pipeline=...) is computed on-demand when trajectory \(m\) is first visited and cached in memory.
    • Simplex Action Projection: Continuous policy outputs \(a_t \in \mathbb{R}^{N+1}\) are projected onto the long-only simplex \(\Delta^{N+1}\) via "softmax", "dirichlet" (concentration sampling during stochastic exploration), or "relu_l1".

    3. Institutional Transaction Costs & Risk-Adjusted Rewards¶

    Pluggable Cost Models (BaseCostModel)¶

    POMDPPortfolioEnv accepts any pyalloq_backtest.costs.BaseCostModel instance—including FlatBpsCostModel, ProportionalSpreadCostModel, and AlmgrenChrissCostModel (non-linear square-root market impact)—and deducts execution costs directly from the step return before passing \(r_{p,t}^{\text{net}}\) to the reward function.

    Online Reward Functions (pyalloq.rl.rewards)¶

    • DifferentialSharpeReward: Moody & Saffell (2001) online Differential Sharpe Ratio: $\(D_t = \frac{B_{t-1} \Delta A_t - \frac{1}{2} A_{t-1} \Delta B_t}{(B_{t-1} - A_{t-1}^2)^{3/2}}\)$
    • StepwiseSortinoReward: Rolling step-wise excess return divided by downside semi-deviation below a target MAR.
    • CARAUtilReward: Log-wealth Constant Absolute Risk Aversion (CARA) utility with quadratic variance, drawdown, and Bures-Wasserstein \(W_2\) turnover penalties.

    4. Continuous Control Agents (SB3PortfolioAgent)¶

    SB3PortfolioAgent orchestrates continuous-control algorithms ("PPO", "SAC", "DDPG", "TD3", "A2C"). When stable-baselines3 is installed (uv sync --extra rl), it delegates directly to SB3 over DictFlattenWrapper(env). In lightweight environments without SB3, it transparently falls back to a built-in PyTorch Actor-Critic PPO implementation.

    from pyalloq_backtest.costs import AlmgrenChrissCostModel
from pyalloq.rl import (
    POMDPPortfolioEnv,
    DifferentialSharpeReward,
    SB3PortfolioAgent,
    RLAllocator,
)

env = POMDPPortfolioEnv(
    scenario_data=scenario_data,
    lookback_window=20,
    cost_model=AlmgrenChrissCostModel(portfolio_aum=1e6, spread_bps=2.0, gamma=0.05),
    reward_function=DifferentialSharpeReward(eta=0.02),
    include_cash=True,
)

agent = SB3PortfolioAgent(env=env, algorithm="PPO", hidden_dim=64)
agent.fit(total_timesteps=10_000)

# Wrap as a standard PyAlloq BaseAllocator for WalkForwardEngine
allocator = RLAllocator(
    policy=agent,
    lookback_window=20,
    use_pomdp_obs=True,
    include_cash=True,
)

    5. Hierarchical Meta-RL (HierarchicalMetaRLAllocator)¶

    Instead of forcing an RL policy to pick raw individual asset weights across noisy universes, HierarchicalMetaRLAllocator operates as a high-level Capital Allocation Committee:

    1. Level 1 (Base Allocators): A sequence of domain-specific BaseAllocator experts (e.g., MarkowitzAllocator, RiskParityAllocator, HRPAllocator, MultiPeriodMPCAllocator) each propose candidate weight vectors \(\mathbf{w}^{(1)}_t, \dots, \mathbf{w}^{(K)}_t \in \Delta^N\).
    2. Level 2 (Meta-Agent): Observes the Bures-Wasserstein regime shift distance \(W_2(\mathcal{N}_t, \mathcal{N}_{t-1})\), Carnot thermodynamic efficiency, and candidate allocator proposals, and outputs simplex blending coefficients \(\boldsymbol{\alpha}_t \in \Delta^K\): $\(\mathbf{w}_t^{\text{final}} = \sum_{k=1}^K \alpha_{k,t} \mathbf{w}^{(k)}_t\)$
    from pyalloq.classical.optimizers.markowitz import MarkowitzAllocator
from pyalloq.classical.optimizers.risk_parity import RiskParityAllocator
from pyalloq.ml.optimizers.hrp import HRPAllocator
from pyalloq.rl import MetaPortfolioEnv, SB3PortfolioAgent, HierarchicalMetaRLAllocator

base_allocators = [
    MarkowitzAllocator(tickers=tickers),
    RiskParityAllocator(tickers=tickers),
    HRPAllocator(tickers=tickers),
]

meta_env = MetaPortfolioEnv(
    scenario_data=train_data,
    base_allocators=base_allocators,
    lookback_window=30,
    rebalance_stride=10,
)

meta_agent = SB3PortfolioAgent(env=meta_env, algorithm="PPO", hidden_dim=32)
meta_agent.fit(total_timesteps=2_000)

meta_allocator = HierarchicalMetaRLAllocator(
    base_allocators=base_allocators,
    meta_agent=meta_agent,
    lookback_window=30,
    tickers=tickers,
)
